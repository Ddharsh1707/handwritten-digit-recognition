# Handwritten Digit Recognition

Recognises handwritten digits 0-9 from 8x8 pixel images with a Support Vector Machine tuned by grid search.

## What you'll learn

- Image classification with SVMs
- Hyperparameter tuning with GridSearchCV
- Visualising predictions

## How to run

```bash
git clone https://github.com/Ddharsh1707/handwritten-digit-recognition.git
cd handwritten-digit-recognition
pip install -r requirements.txt
python main.py
```

No dataset download needed: the data is built into scikit-learn or generated by the script.
